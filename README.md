# You're the Distraction

Pixathon — Open Innovation Puzzles. Status: design handoff; no playable build yet.

You are an office ghost. Arrange up to three distractions, then press Play to help an employee escape without their boss noticing.

Open CODEX_HANDOFF.md in your Codex project and ask Codex to implement it. AGENTS.md defines ongoing version and prompt logging requirements.

## Repository history

The accompanying repository.bundle contains the initial Git history, tagged v0.0.1. Restore it with:

```sh
git clone repository.bundle youre-the-distraction
cd youre-the-distraction
```

The other files in the download are convenient readable copies. Use the cloned repository for further development.

Create an empty GitHub repository, then substitute its actual URL:

```sh
git remote add origin https://github.com/YOUR_USERNAME/youre-the-distraction.git
git push -u origin main
git push origin --tags
```

GitHub publication has not happened. Do not commit passwords, tokens, .env files, or unrelated uploads. If Git requires an identity, configure your own name and GitHub verified/noreply email. The initial documentation commit is attributed to Codex, not to the user.
